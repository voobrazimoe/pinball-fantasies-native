# Pinball Fantasies v0.1.2 prerelease

Native macOS 13+ support is now available for Apple Silicon (ARM64) and Intel (x86_64), using an AppKit/Core Animation/AudioUnit host. Windows and Linux x86_64 builds remain included.

All four tables share the existing engine across platforms, including multiplayer, scrolling modes and full-table view. Real-Mac gameplay acceptance confirmed responsive scrolling and flippers. The persistent **View → Swap Left/Right Shift** option corrects Macs that report the Shift sides reversed.

Public builds contain no commercial game data. Supply your own legally obtained supported DOS files as described in the README; PINBALL.CFG is optional mutable player state.

The macOS apps are ad-hoc signed, without Developer ID signing or notarization.

This release does not include Android support.
